# Repository instructions

## Local-only development artifacts

- Store investigation notes under `docs/investigations/`.
- Store Superpowers implementation plans, design specs, and execution notes under
  `docs/superpowers/`.
- Treat both directories as local-only scratch space. Do not stage, commit, or
  force-add their contents, including through GitHub API tools.
- Follow this repository rule even when a Superpowers skill asks you to commit a
  plan or specification. Do not move these artifacts to another tracked path to
  bypass this rule.
- Keep durable project documentation, such as `README.md`, `ARCHITECTURE.md`, and
  the public guides directly under `docs/`, in version control.
